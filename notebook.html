Engineering findings

  • The ARM64 aapt2 trap that eats Android builds on-device
    2026-09 · Android · build systems — Gradle silently downloads an x86_64 binary and every build dies with “required file not found”. The fix is one Gradle property, and it has to be present before the first build.
  • Zero tokens from a perfectly good GGUF model
    2026-10 · LLM inference · root cause — one boolean in the chat-template call made greedy decoding answer with an end-of-turn token. Plus a KV-cache issue that kills the session after ~7 turns.
  • MediaPipe model bundles never start with “PK”
    2026-10 · on-device ML · measured bytes — real .task bundles put the ZIP header at offset 2 or 4. A guard that requires it at byte 0 rejects every genuine file.
  • Debugging a native engine you are not allowed to run
    2026-10 · debugging method — when the app cannot be installed, rebuilt, or tapped, rebuild the same native library for Linux and mirror the JNI path line by line.

Design notes

  • Tasks are not goals: the FIND/DO layer model
    2026-10 · agent architecture — every Android task decomposes into ordered layers, each a pair of “find the right target” and “do one operator on it”, with a mandatory trace and a confirm window.
  • The voice-as-touch category is structurally empty
    2026-09 · landscape research — ~2,000 repos swept, 42 curated, 12 issue trackers mined. The ecosystem built goal-executing agents; nobody built the primitive layer.
  • Fix the signal before you filter it
    2026-09 · computer vision — four defects that all sat upstream of an existing smoothing filter. The filter was working perfectly; it was fighting a signal that had already been destroyed.
  • One plan, two renderings: why the lips cannot disagree with the sound
    2026-10 · system design — driving a face and a voice from the same intermediate plan removes an entire class of synchronisation bugs instead of fixing them.

Method

  • GitHub as a lab notebook, honestly assessed
    2026-10 · research practice — what version control genuinely provides (timestamped provenance, citability through DOIs), what it does not (priority, a patent record), and the adoption data.
  • GitHub Pages: the limits that matter, and the one that doesn’t
    2026-10 · hosting — the numeric quotas are irrelevant for a text site. The commercial-use clause is not, and it decides where a business site can live.
