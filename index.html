What I do

On-device AI systems

Android agents that need no cloud: on-device LLM inference, offline speech-to-text, accessibility-driven task execution, and a decision layer that scores every candidate action.

From-scratch engineering

Selected work

AndroidAgentRebuilding

Cosmo — offline Android agent

Voice → decision → action, entirely on the phone. Offline STT confirmed working on device; the first execution model was rejected by real device testing, so v2 is being rebuilt around a layered FIND/DO architecture with a mandatory per-step trace.

Device-tested · 8 defects found and fixed in round one · architecture rewritten from scratch

WorkingFrom scratch

Anima — talking avatar, written from pure math

A human model built with no third-party libraries: hand-written phonemizer, formant voice synthesis, viseme curves, a 3D rasterized face, a neural language model, and ears that learn from its own voice.

Perplexity 2.6 vs unigram 44.1 · gradient check 4.0e-08 · unseen-voice recognition 100% · mirror symmetry 0.000000 mm

ShippedAndroid

MiniKeys — modular Android keyboard with cloud AI

A keyboard built as reusable Gradle modules, including an OpenAI-compatible client and an Android-Keystore key vault. The offline-inference experiment was deliberately removed after a native crash I could not evidence — and the removal was verified byte-level.

APK 8,710,088 bytes · 14/14 unit tests green · zero native libraries after removal

ShippedFrom scratch

LLM Lab — a tiny GPT, twice

A decoder-only transformer with a hand-written backward pass, plus an Android app that reimplements the same model in Kotlin, trains it live on screen, and loads the reference checkpoint.

Kotlin vs NumPy agreement: max |Δp| = 1.513e-07 · APK 9,862,893 bytes

Device-testingComputer vision

EyePoint — eye-gaze pointer

A phone-wide overlay pointer driven by gaze. Built as a fresh fork after I traced the predecessor's jitter to four code-level defects upstream of its smoothing filter — including a right-eye landmark bug.

4 root causes documented · v0.1.1 shipped · pipeline rebuilt layer by layer

VerifiedInfrastructure

android-build-ship — a verified build skill

A written, versioned procedure for building and shipping Android apps on this device, with a project template. Dogfooded on itself: the first repo it created was its own.

Deployed and reused across 6+ projects · defect found and fixed by inspection before first build
