RebuildingAndroid

Cosmo — offline Android agent

An agent that takes a spoken order and executes it on the phone with no network. Three components, one app: an on-device decision engine that scores candidate targets, an on-device language model for the ambiguous work, and offline speech input.

Device testing proved the speech front-end and a single execution layer, then rejected the execution model itself: no termination semantics (tasks re-ran in a loop) and a wrong candidate pick. v2 is being rebuilt around ordered FIND/DO layers with a mandatory per-layer trace and a step-confirm window.

Round-1 device test: 8 defects found, fixed, and re-verified · architecture replaced

Device-testingCV

EyePoint — eye-gaze pointer

A full-screen overlay pointer aimed with the eyes, intended as the first input source of a hands-free phone. Built as a fresh fork once the predecessor's jitter was traced to four defects that all sat upstream of its smoothing filter.

Root causes: right-eye vertical landmark mix · normalization denominator switching · ×20 gain before filtering · no head-pose compensation

Device-testingAudio

LibreCuts BeatLab — instrument detector

An instrument (not merely beat) detector added to an open-source Android editor: every played moment per instrument, per beat, delivered on a multi-timeline you can edit against.

Ordered in two versions — one using proven libraries, one written from the base with pure code and mathematics — so the two can be compared directly.

Base chosen from a 10-project GitHub landscape · MIT-licensed foundation

ShippedFrom scratch

Anima — talking avatar

A model of a human, written from the ground up with no third-party libraries: phonemizer, formant voice synthesis, prosody, viseme curves, a 3D rasterized face, a neural language model with hand-derived backpropagation, and ears that learn from the avatar's own voice.

The face is driven by the same plan that produces the audio, so lips and sound cannot disagree.

Perplexity 2.6 (unigram 44.1) · gradient check 4.0e-08 · same-voice / unseen-voice / stranger-voice recognition 100% · "hello" recognized at 3 dB SNR · mirror symmetry 0.000000 mm over 2,511 samples · boot from disk 0.3 s

A keyboard assembled from reusable Gradle modules, including an OpenAI-compatible cloud client and an Android-Keystore key vault. An offline-inference experiment was built, debugged, and then removed on request after one engine crashed the app with no crash record to investigate.

APK 8,710,088 bytes (down from 71 MB) · 14/14 unit tests green · zero native libraries · removal verified by scanning every classes*.dex

LandscapeAndroid

Voice-as-touch — category landscape

A systematic sweep to answer one question: does a voice replacement for touch primitives already exist? Answer: no. The ecosystem converged on one-shot agents; the primitive layer exists only as abandoned single-author repos.

~2,000 repos swept in three keyword waves → 42 curated with verified metadata → 12 issue trackers mined for real failure evidence
